# TELECOM-X – Análisis de Churn

Este proyecto es un ejercicio básico de análisis de datos donde se estudia el problema de **Churn (evasión de clientes)** en una empresa de telecomunicaciones.

El objetivo es entender qué características tienen los clientes que cancelan el servicio y compararlos con los que permanecen.

---

## Trabajos realizados 

- Se cargaron los datos desde un archivo JSON.
- Se normalizaron las columnas que estaban en formato diccionario.
- Se limpiaron datos nulos y se revisaron duplicados.
- Se analizaron:
  - La distribución general de Churn.
  - Churn según género.
  - Churn según tipo de contrato.
  - Churn según método de pago.
  - Total gastado vs Churn.
  - Tiempo de contrato vs Churn.
- Se usaron gráficas de barras, pastel y boxplots para visualizar los resultados.

---

## Conclusiones principales

- Los contratos **mes a mes** tienen más churn.
- Los clientes que pagan con **Electronic check** cancelan más.
- Los clientes que cancelan suelen tener menos tiempo de contrato y menor gasto total.
